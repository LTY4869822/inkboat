# 按场景截图：唯一当前决策规则

本文件统一截图范围。其他文件中的历史局部采集、一屏案例是验证记录，不构成所有题材的固定范围；当前用户明确要求优先。

| 场景 | 截取范围 | 读者必须能看见 |
| --- | --- | --- |
| 注册、安装等教程 | 完整一屏，框出操作区域；必要时一操作状态一图 | 位置、控件、输入及成功状态，正文逐步说明 |
| X案例整帖交付 | 完整帖子，可保留原始长帖或真实滚动拼接 | 作者、全部正文、附件、绝对日期和互动数据；回复不属于整帖 |
| 复杂图表 | 完整相关图表及影响结论的条件 | 对象、图例、坐标、单位、设置；旁边中文说明重点 |
| 视频案例 | 真正展示过程/结果的关键帧 | 作者与视频关联、实际时间点、前后状态；静态图不证明交互或声音 |
| 公告、产品说明 | 能完整支持该段的功能区域及上下文 | 具体功能、入口、条件或结果，避免只截标题/Logo |

`screenshot_plan.py choose --kind tutorial|x-post|chart|video-result|announcement`返回范围建议。它不采集页面、不证明截图真实。真实采集依宿主工具文档执行，不修改网页DOM，不绕过访问限制。

## 中文整帖与长帖

用户要求中文X截图时：中文原帖保留原文；外语帖使用原平台翻译，确认实际看到中文正文和翻译状态。切换账号语言属于账号设置，遵守用户授权，完成后恢复原设置。只把界面切为中文、只翻译标题、机器排版成“推文卡片”均不算原生中文截图。无法显示原生中文时报告具体帖子与障碍，可另交原图和正文中文解释，不能冒称中文截图完成。

先尝试宿主支持的完整帖子采集。后端fullPage/clip异常时，仅做一次有根据的修复；仍失败转真实视口滚动采集，避免重复调用同一坏接口。用约0.8屏滚动保留重叠，实际检查固定顶栏、段落和接缝。移动媒体完整保留在同一片段，不能将不同播放时刻的两半拼在一起。每个原始片段保存SHA、裁切矩形与拼接顺序；逐接缝看像素，不凭算法输出认定无缺字。长帖用于交付时保留完整文件；插入文章时若手机缩放难读，按自然段拆成连续片段并保留完整原帖内部备查。

这些拼接办法来自2026-10-06十条中文完整案例采集。十条中只有两条有Claude Code入口证据，其余明确区分模型与其他入口；以后筛选时先核验产品/模型/版本，再计入对应要求的案例数量，不用近似材料凑“已完成十条”。传播数据按实际采集时间记录，不能声称全网最热排名。

## 无账号与停止条件

信息读取和原生截图是两种能力。公开链接抓取可无账号；原生X页面、平台翻译及某些媒体可能要求登录。Nitter是可选能力，本机部署也可能需要上游会话，不能当成无账号保证。没有X账号时继续公开索引、可访问原帖、作者项目与实际演示；需要特定截图仍不可得，列出准确缺项，让用户选择补图或采用可访问的证据，不反复要求注册。

`operations.py retry --run RUN --resource 不含URL的ID --outcome failed|login_required|access_denied|success`记录尝试；普通失败最多两次，明确登录/权限阻断直接分流。其状态是建议停止，Agent须实际执行，不冒称脚本替代了浏览器。

整帖任务将screenshot-ledger.json交给`screenshot_plan.py check --run RUN --records 文件`。captured记录original_file/sha256、kind、visible上下文、translation；scroll-stitch另有assembly_file，记录原始fragments及接缝与媒体审阅。待补项逐条写need/reason/tried/help_action。文件验收检查溯源与完整性记录，仍须实际看图。

所有框线只叠加几何标注，按screenshot_annotations.py逐像素验证；不得重绘、替换译文或删除限定条件。每张图片回答具体问题，数量与画风仍由正文决定。
