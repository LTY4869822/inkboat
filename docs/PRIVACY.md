# 隐私与凭证

## 公共仓库里有什么

Skill 规则、脚本、五套原创主题、工坊静态资源、测试、保留许可的第三方资源，以及原创演示稿和效果图。不包含开发者的公众号账号、个人文章、平台会话、原始文章学习语料和独立教程版。

## 工作资料留在哪里

| 资料 | 位置示例 | 分享建议 |
| --- | --- | --- |
| 账号标识与偏好 | 工作目录 `.wechat-ai/` | 含公开ID也不默认分发 |
| 独立浏览器登录 | `.wechat-ai/browser-profile/` | 不分享、不进 Git |
| 搜索工具环境 | `.wechat-tools/` | 按需要本机配置，不打包会话 |
| 个人文风 | `.wechat-ai/writing-styles/` | 仅在你明确迁移时复制 |
| 文章、来源、原图 | 各篇 run | 对外给稿前核对素材与隐私 |
| 密钥 | 本机环境或宿主安全配置 | 不发聊天、Issue、日志与截图 |

AppSecret、API Key、X Cookie、验证码和登录二维码不能当成公开复现材料。项目不提供共享账号，也不从其他浏览器偷偷导出 Cookie。

## 网络边界

写作中的搜索、模型、生图及平台访问会由宿主或所选工具发出。使用外部模型前，请按自己的数据要求选择提供方。Agent 不应自动把私有全文、密钥或登录请求转发给未经授权的服务或代理。

工坊服务仅绑定 `127.0.0.1`，限制本机 Host 与写入 Origin。不要反向代理到公网或把本机服务端口开放给他人；它用于个人本地创作，不是多用户网站。

## 分享前检查

只从声明的 skill 文件集合打包，不打包整个工作目录。仓库检查工具和 `.gitignore` 能拦截部分明显误带，不能代替人工核对，也不是全面安全审计。

效果图使用原创演示稿，避免私人聊天、账户菜单、临时阅读链接、登录二维码或后台 token。发现泄露时先撤销对应凭证，再按[安全报告](../SECURITY.md)联系维护者；删除最新文件不能撤销已经公开的历史。
