## 正式稳定版前希望补齐

1. 五位未参与开发者的独立安装、写作、预览、保存、确认与入稿记录。
2. 实体微信客户端不同设备、浅色/深色、表格与动效验收。
3. 有接口权限账号的官方 API 真实写入及阅读核对。
4. 多宿主与实际 macOS/Linux 机器的端到端验证。
5. 每条传输路径完整计时和失败恢复统计。

不公布未经实测的省时百分比、成功率或“所有平台都接通”之类承诺。欢迎提交带环境和复现步骤的反馈。
