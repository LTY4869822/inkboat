# 公众号连接、草稿与发表

## 默认授权范围

墨舟默认制作并预览文章，用户确认当前保存版后，按本次指令存入已连接公众号草稿箱。**保存工坊、点击模板或生成预览不构成发表授权。** 正式发表必须有当前明确指令。

原版脚本的 `fast_publish.py` 和 `browser_draft.cjs` 负责草稿，不提供一个绕过微信扫码及审核的“无人值守发布”开关。明确授权的正式发表由宿主通过可用的正常平台能力处理，并核对最终状态。

## 首次连接

1. 用你自己的公众号登录。独立浏览器资料目录与宿主内置浏览器不是同一个登录态，可能需要单独扫码。
2. 从官方账号详情实际核对名称与原始公众号 ID，再保存到当前工作目录。
3. Agent 根据真实 DOM 标定标题、正文、图片上传、封面和保存控件。安装包不携带开发者的选择器绑定、账号或 Cookie。
4. 后续有效登录可以复用，登录过期仍需扫码。不能从用户别的浏览器中偷偷复制会话。

浏览器路径不需要 AppSecret。凭证不要发到聊天或 Issue。

## 两条草稿通道

| 路径 | 前置条件 | 主要边界 |
| --- | --- | --- |
| 官方 API | 本机凭证、账号权限、出口 IP 白名单及素材条件 | 模拟测试不等于账号实际可写；有 SVG 或过大 HTML 时保守分流 |
| 独立浏览器 DOM | 自己扫码的专用资料目录、可用浏览器与选择器 | 正常 UI 上传、HTML 剪贴板粘贴、封面裁切与重开核验 |

确认保存版并完成审阅后，由 Agent 执行：

```text
python SKILL_ROOT/scripts/fast_publish.py plan --run RUN
python SKILL_ROOT/scripts/fast_publish.py deliver --workspace WORKSPACE --run RUN
```

`SKILL_ROOT`、`RUN`、`WORKSPACE` 是实际路径位置。`deliver` 不是免配置命令；需要前面的版本采用、质量、账号绑定及当前授权。完整命令见[内部快速通道](../skills/wechat-ai-autopilot/references/fast-publishing.md)。

## 必须核对什么

- 标题、摘要、全文顺序、字体及黑色普通正文。
- 原图身份、顺序与加载，不能把 1×1 占位图算成功。
- 2.35:1 横封面和 1:1 转发封面，实际检查中心标题区域。
- 当前动效结构，以及保存并重新打开后生成的新官方阅读页上的两次回播。
- 草稿 ID 与账号一致；已有本篇稿号就更新它，不因结果不明另建重复稿。

微信会正规化 HTML、表格并压缩图片，不承诺字节相同。严格检查失败要保留，调查差异，并以当前官方阅读页核对可见效果；不能放宽规则或直接把失败改成通过。

## 正式发表与安全验证

明确授权发表后，平台可能额外要求管理员或运营者扫码。登录扫码和发表安全验证是两件事。用户完成验证以后，仍要查看发表记录：

| 状态 | 能怎样汇报 |
| --- | --- |
| 草稿已保存 | 已入草稿，尚未发表 |
| 微信安全验证待完成 | 需要管理员操作，不能绕过 |
| 审核中 | 已提交申请，尚未确认公开发表 |
| 已发表且正式链接可打开 | 可以报告发布成功 |
| 审核失败或返回错误 | 保留原因，先查状态，不重复提交 |

正文没有生图图注，不代表后台来源申报可以随意处理。实际要求的申报、原创和群发设置按用户授权及平台规则办理，不伪造、不隐藏、不擅改。

实体微信客户端与深色模式应单独验收；桌面手机宽度及模拟触屏不替代真实设备。
