# 文风与文章学习

## 内容学习与文风学习不同

**内容学习**研究选题、案例、信息密度、论证与读者收益，不会自动生成一个新作者风格。**文风蒸馏**研究表达与组织方式，完成校准后才进入写作选项。

默认只学习内容，不借鉴样本排版。可以指定只学某类文章、只学截图选择，或者先看总结再决定是否合并。用户授权直接合并时照办，不机械追加确认。

## 内容学习示例

```text
读我提供的这些公众号文章，只学习内容组织和截图选择。
总结不同选题应该写什么，先给我确认，不修改规则。
```

实际阅读全文，保存原始链接、阅读进度、摘要与可定位段落，区分已读、无法访问和只看到摘要。不能把搜索摘要或平台 AI 总结算作读完正文。

继续同一批时，依据链接和文本哈希去重；仍需补读缺少的文章，不把脚本登记成功当成阅读完成。

## 新增文风的流程

1. 收集通常至少二十篇可完整读取的文章。少量样本只形成初步观察。
2. 真正读全文，识别稳定的语言、节奏、结构与取材习惯。
3. 按 Writing DNA 规则产出五份风格文档。
4. 校准相关样本，并写一篇新题目的原创样稿。
5. 审查事实、原创性与风格一致性；合格后注册到个人风格库。
6. 下次写作动态列出已完成的风格，与卡兹克入口一起供选择。

```text
用这30篇完整文章蒸馏一个新文风，名字叫“清楚讲理”。
写原创样稿验证，合格后加入我的文风库；不要复制作者经历。
```

用户要求先确认时，先交文档和样稿，不自动注册。文档缺失或损坏时不能静默退回另一种风格。

## 卡兹克入口的含义

已安装 `khazix-writer` 时按该实际 skill 执行；未安装时明确采用本包编辑写法简版。风格影响措辞、节奏与组织，不代表冒充作者、复制历史文章或声明得到作者认可。

写完依次用 Humanizer 与独立 Lieflat 审稿，仍须保留所选风格。两道审稿不能把事实改掉，也不能为“更有人味”添加虚构经历。

## 数据在哪里

个人风格保存在工作目录 `.wechat-ai/writing-styles`，学习批次和全文记录也留在工作目录。它们不是公共 skill 的组成部分。本仓库不携带开发者阅读过的150篇全文、个人文章、已经登录的公众号或私有学习库。

更换电脑时由你显式迁移自己的资料，并确认语料使用权限。公开分享新风格前，应去除原文、私人经历和不能再分发的样本。
