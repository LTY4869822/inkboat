# 常见问题

### 这是一个网站或桌面软件吗？

不是。它是给 Agent 使用的 Skill 与本地工具集，文章工坊是每篇生成的本机网页。它需要宿主提供模型、搜索、浏览器或生图工具。

### 为什么名字是墨舟，调用仍是 wechat-ai-autopilot？

墨舟是公开品牌；保留原 ID 避免已有安装、命令和学习记录的兼容变化。自然语言也可以直接称呼墨舟。

### 必须配置 OpenAI API Key 吗？

不必须。优先使用宿主已提供的能力。无内置生图时才询问是否配置及具体模型，不能默认替你选择付费服务。

### 不登录公众号能试用吗？

能。先生成本地文章或运行演示，查看十套排版与工坊。只有进入草稿传输时才需要你自己的账号通道。

### 为什么不能直接用文件双击工坊完成所有功能？

保存、版本和导入需要本机服务。用 `studio.py serve --run RUN --port 0` 或演示命令启动，打开实际输出的地址，不固定写死端口。

### 只复制 SKILL.md 可以吗？

不行。脚本、主题、工坊与参考规则都在同一完整文件夹里，缺文件不能完整运行。

### 提示周行依赖缺失怎么办？

安装原项目中的完整 skill 文件夹，或通过个人配置指定路径。脚本找不到实际渲染器时会拒绝声称成功，不会悄悄换另一套排版。

### 十套排版的文字怎么都是黑色？

普通正文、列表和普通表格单元统一黑色，便于阅读；标题、强调、链接、代码和标志性设计仍有主题色。读者设备没有你选的字体时会回退。

### 已保存的修改为什么没上传？

检查是否是“保存当前文章”，而不是“另存模板”；确认的是不是最新版本；有无未保存调整；正文变化后事实与图片映射是否已更新。Agent 不能用默认重排覆盖你的保存版。

### 为什么正文没有来源编号？

读者正文与内部核验分开。来源、事实映射与图片依据仍保留。没有显示编号不允许虚构事实或冒认发现。

### 找不到某张真实截图怎么办？

先自己采集，再查官方或可靠原作者的对应画面，仍缺则逐项说明需要用户补哪张图。不能用生图重画界面，或用占位图当完成。

### X 没账号是不是完全不能研究？

不是。可先读取公开链接或公开索引；站内检索、完整翻译截图和部分材料可能需要授权登录。文本读取、搜索与截图分别报告，不承诺没有登录就覆盖全部内容。

### AIhot 又失败了要不要一直重试？

不要。做一次有信息的诊断，区分连接、服务和返回结构，保留时间，再切换真实可用来源。缓存不冒充实时。

### 动效在预览里能动，微信里不能动怎么办？

平台可能过滤 SVG 引用或改变事件。优先四类已验证构图，入稿后打开新官方阅读预览，等自动播放结束后点背景并第二次回播。失败保留记录，不偷偷关掉动效来声称上传完整。

### 会自动发表吗？

默认只入草稿。正式发表需要本次明确授权，可能要求管理员扫码，之后还需平台审核。“审核中”不能汇报为“已发表”。

### API 可用就一定比浏览器快吗？

不能这样保证。账号权限、HTML、原生动效和素材条件决定通道。无端到端对照测量，不承诺固定速度或成功率。

### 能不能一键装好并打通所有平台？

不能。安装包不应携带别人的账号或会话。环境检查、平台授权和真实验收是复用者自己的步骤，Agent 会按当前可用能力推进。

### 出错怎样报？

提供版本、系统、宿主、命令、脱敏错误、发生阶段与最小复现。不上传 `.wechat-ai`、Cookie、密钥或含 token 的后台链接。见[贡献指南](../CONTRIBUTING.md)。
